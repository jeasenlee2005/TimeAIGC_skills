# 场景尺度确认模板

仅在项目没有有效尺度记录、实测冲突或场景几何变更时使用。已有确认且实际校准通过的场景不重复询问。

请确认这份场景采用的实际比例：每 1 个 Blender 单位代表多少米？如果不确定单位设置，请给一个场景中可定位物件的已知长度，例如指定门洞宽或校准方块 X 方向长度，并说明单位。

助手随后记录：

| 记录 | 含义 |
| --- | --- |
| 场景 ID / 文件版本 | 实际采用的无人场景 |
| meters_per_blender_unit | 每 Blender 单位对应米数；米制常见 1，厘米制常见 0.01，不凭显示标签猜 |
| calibration.object / axis | 真实可读取的网格对象名与世界 X/Y/Z 测量轴 |
| calibration.length_m | 用户或工程资料确认的现实米值 |
| calibration.tolerance_m | 明确的测量误差容限 |
| source | 实际确认依据 |

Blender 实测世界范围乘单位换算必须匹配已知米值。200 单位 × 0.01m/单位 = 2m；把 2 单位长的物件仅改成厘米标签不等于 2m。源场景保持只读；人物、位置和相机的米值只换算一次，不重复缩放。

冲突时同时展示登记比例、实际测量及预期米值，等待必要确认。不要修改单位标签或重填哈希来“让检查通过”。
