# 合并到现有 AGENTS.md 的项目入口块

这是供助手合并的模板，不是替换整个项目说明的文件。先读原 AGENTS.md，只添加或更新以下标记块，保留块外全部内容；登记文件采用项目相对路径。没有 AGENTS.md 时再新建，不改其他项目或安装目录。

## TimeAIGC 预演接续入口

为本项目制作预演时，先读取 `.timeaigc/project.json`，再读取其 `character_registry.path` 指向的角色尺度登记。场景、分镜和采用版本以实际项目文件为准，不依赖历史聊天记忆。

先用已确认的第一阶段全项目完整片段总表，缺少时读取完整剧本；两者都没有时请求完整资料并等待，不从所选片段猜全项目人物。核对已有确认后，首次批量询问缺少的身高、模型选择和尺寸；以后只问新增、缺失或冲突。人类总高含头；非人类先选已有模型、简化形状代理或占位体，再明确尺寸语义。变身单独登记形态。

保持原确认来源、角色 ID、别名、形态和尺寸；图片或路径改变不清空尺寸。实际场景单位须经已知尺寸对象测量。只载入本片出场角色，镜头位置/朝向不能覆盖固有尺度。修改模型/尺寸后将依赖预演标记过期，保留历史媒体和快照。

`existing_model` 从登记的本地 `.blend` 精确集合加载原网格，读取模型及实测契约的相对路径/哈希/版本；不得换成新体块。新模型先按独立技能的 `references/local-blend-models.md` 检查并保存契约后登记。有效记录直接复用；缺文件、错误集合或不支持输入只处理该问题，不清空已确认尺寸。源模型只读，禁用自动执行。

使用本项目明确指定的独立 v2.2 技能副本执行；缺少该副本时先定位文件，不使用旧版默认值冒充。生成材料只引用已验证的干净视频；说明版只供观看。未授权时不提交付费生成，不安装覆盖原技能。
