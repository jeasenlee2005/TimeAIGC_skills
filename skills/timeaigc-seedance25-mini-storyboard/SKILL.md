# Seedance 2.5 单片段迷你分镜

把一段情节转成一条可独立生成的5–30秒视频分镜。保留完整分镜的画面质量，缩短资料准备与交互流程，不把“迷你”理解为删掉构图、站位或动作因果。

## 1. 接收并理解资产

- 收到图片时实际查看；保留图片标识或可用原路径，按图简记角色身份对应、发型服装、关键道具、场景布局与光源。区分可见事实、用户设定和不确定事项，不凭文件名编造内容。
- 角色三视图、拼图及场景多视角图是同一资产的参考，不当作多个人物或要求生成拼接画面。
- 只有资产图时，简短反馈已识别内容，一次询问情节及5–30秒内的目标时长；不提前编剧情。角色对应不清且影响故事时一起询问。
- 资产、情节和时长已齐时直接生成，无需再确认大纲或全局风格。有用户风格要求时遵守，否则沿用适用资产的视觉基线；只询问影响输出且无法保守解决的冲突。
- 用户明确不用图片时可按文字设定工作。缺少某张图不自动阻塞全部任务；只询问影响身份、关键动作或剧情的缺口，普通调度可合理设计。
- 复用已看过的图片和可靠视觉记录，不每次修改都重读全部图。多套服装或场景状态先选择本段适用版本。图片新增、版本变化、事实冲突或关键细节缺失时仅补读相关图；找不到原图就说明缺口，不假装看过。
- 上下文压缩后先恢复可用的资产事实；文字记录不能保证包含全部视觉细节，只在当前决策需要时补看原图。

## 2. 将情节组织成可拍的一段

- 获取明确目标时长T，满足5≤T≤30秒，可有小数。时长缺失时询问；只给范围时请用户确定具体值，明确授权自行安排时才在范围内选择并说明。
- 超出范围时说明单段范围，询问改成范围内的时长或另用长剧情流程；不静默截断、不自动拆成多段。
- 保留核心事件、动机、顺序、结局和指定台词。允许补充必要的动作连接、视线、站位与反应，不擅自增加角色、冲突、能力或反转。影响理解的补充假设放正文外简述。
- 按“起始状态—触发与行动—反应或结果”组织内部节奏，允许从动作中途起镜；不先输出冗长的步骤一方案，不要求再次确认同一情节。
- 根据动作完成点、对白覆盖和信息变化切镜，不设镜头数硬配额。简单5秒片段可1–3镜；10–15秒常用3–6镜；20–30秒常用6–12镜，均为参考。持续动作或表演可用长镜头，不为凑数量切碎动作或补剧情。
- 时间轴从0开始，相邻镜头首尾相接，最终等于T；不留空洞、重叠或超过30秒。给动作、沉默和结尾反应留实际时间，不为凑时长强行慢动作。
- 原台词完整保留、顺序不变且每句只出现一次。未给台词时默认用动作讲故事；只有要求补写对白时才创作新台词。
- 中文台词粗估每个可朗读字符约0.3秒，另留停顿与表演时间；这是工作基线，英文及特殊读法按实际朗读复核。画中文字不当作发声台词。跨镜台词按实际覆盖时间评估，明确“声音连续至X秒”，不要求整句塞进首镜。
- 内容或原台词无法在T内自然完成时，指出具体冲突并请用户选择删减或调整时长；未经授权不删台词、不靠极快语速掩盖超时。

## 3. 编写清楚完整的镜头

- 每镜写出景别、机位和运镜，固定镜头明确写“固定机位”。短镜头通常只安排一个主要运镜；复杂运动说明先后与触发点。
- 正文必须落实主体的画面位置、站坐姿态或朝向、视线/动作对象及相关人物或场景的空间关系。不能只剩“她转头，很惊讶”，也不能用顶部角色名单或构图术语代替站位。
- 单人镜头说明取景落点与对象；多人互动明确双方位置、前后或遮挡；局部特写说明画内局部与接触对象，不硬塞画外全身。焦点、虚实影响观看对象时明确写出。
- 默认用“画面左侧/右侧/上方/下方”描述屏幕位置；前后远近另写，不把上方当远处。左手、右脸等身体自身左右保持真实设定；切机位维护轴线和地理关系，不强求每个机位中人物处于相同屏幕位置。
- 用具体画面替代抽象构图解释。例如“女子站在画面右侧，望向左侧半开的门”。过肩明确谁的肩背在何侧、主体位置及焦点；对称、三角等构图写出中轴或支点，不只报名称。
- 构图随叙事变化，避免机械居中或轮换术语。自然透视、观看和运动空间优先；不为交代所有人强行塞入画面。实际可见的背景角色保留简要位置与状态，远处小人物不要求精细五官和口型。
- 维护造型、持物、伤势、光源、动作起终点与空间连续性。多人动作交代谁作用于谁、运动或接触方向及反馈，避免道具换手、瞬移和无故复原。
- 情绪用符合景别的自然视线、眉眼、嘴角、姿态、呼吸或停顿表达；少量准确表演优于夸张强度词。远景不用精细眼部变化。
- 将助手新增的“眼露寒芒、目光如炬、内心冷光”等比喻转成实际表演；普通情绪不导致眼睛发光变色、血管膨大或突然改光。沿用原有光源与时段，只有明确物理变化或用户授权特效才改变；保留真实眼部反光和已设定能力。原对白中的比喻保持原话，不转成可见光束。
- 本段独立可理解，直接写当前地点、必要造型、持物和动作起点，不写“承接上一段”“服装同前段”“省略赶路过程”。用户明确要求的视频延续或段内回忆转换按实际素材处理；原台词中的前情不删。
- 对白用【对白】、画外发声用【OS】、旁白用【旁白】，标明说话人并用中文双引号。按真实时刻嵌入动作，让表演与语言同步；OS/旁白不要求画中人口型。仅在有依据或用户要求时补声音，不堆质量词或长串负面提示。
- 不设每镜字数下限或强制截断上限。先保留必要画面关系与因果，再删除重复、抽象评价和无用摄影参数。

## 4. 一次检查后交付

草稿完成后合并检查：时间是否准确、台词能否说完且未改漏、每镜构图站位是否清楚、动作与道具是否连续、镜头指令是否兼容、资产与光影是否一致、是否无故新增特效或剧情。修正具体问题，只复查受影响镜头及相邻状态，通过后交付；不反复润色计字或重读全部资料。

输出一份完整分镜代码块：标题、总时长、影调氛围、出场角色、所在场景，然后逐镜时间轴与正文。格式及完整示例见[分镜输出示例](references/output-example.md)，首次需要确认格式时读取，修改时无需反复加载。

- 影调氛围写本场景可见照明和氛围，不把情绪作为换色指令。角色栏保留辨识造型与版本；场景栏给必要布局。指定的整体媒介风格可简短融入影调氛围，不每镜复述。
- 镜头行统一为`0-2秒：【镜头语言：景别/机位 + 运镜】具体画面与表演`；时间用阿拉伯数字，可用小数。
- 不输出内部推理、逐项检查表或长篇策略说明；必要假设、冲突或资产缺口放代码块外，无阻塞时直接给成稿。
- 修改只涉及指定范围及必要的相邻连续性，默认返回更新后的完整单段脚本；用户要求仅给差异时遵从。
- 不自动创建项目AGENTS.md、方案库、资产归档或交接流程，不强制保存文件；要求保存时写入指定位置。后续新片段可复用资产事实，但重新接收本段情节与时长，不将上段剧情混入。
