# 单片段输出示例

此例演示格式与信息完整度，不是默认剧情、镜头数或字数模板。实际使用用户资产、情节和目标时长。

示例输入：女子穿米色外套，男子穿深蓝夹克；白天门厅，左侧木门、右侧小桌，窗光稳定。女子准备出门，男子将桌上的钥匙递给她，她接过后离开。无对白，目标10秒。

```text
# 单片段：门口的钥匙
总时长：10秒
影调氛围：白天柔和窗光，室内光色稳定，日常自然。
出场角色：女子，米色外套；男子，深蓝夹克。
所在场景：门厅，木门位于画面左侧，小桌靠右侧墙；两人之间通道畅通。

0-3秒：【镜头语言：中景/门厅内平视 + 固定机位】女子站在画面左侧木门内，身体朝门外，右手握住门把。男子在画面右侧桌边，右手拿起桌上的钥匙，转向女子并伸出手。女子停住开门动作，回头看向他的手。
3-5.5秒：【镜头语言：近景/两人侧面略俯拍 + 固定机位】男子伸出的右手从画面右侧进入，钥匙垂在画面中央；女子左手从左侧伸来，掌心向上接住钥匙，男子松手收回。焦点落在两只手与钥匙上，后方木门虚化。
5.5-7.5秒：【镜头语言：中近景/男子肩后平视 + 固定机位】男子肩背在画面右下角虚化，女子位于左侧门边，面部清晰。她左手握着钥匙，抬眼看向男子，嘴角略微扬起，轻轻点头，随后转头看向门外。
7.5-10秒：【镜头语言：中景/门厅内平视 + 固定机位】女子在画面左侧用右手推开木门，左手仍握着钥匙，迈步走出；男子站在画面右侧的小桌旁，手臂自然垂下，视线跟随她离开。木门在女子身后缓慢回摆。
```

- 只有资产图：查看并概括实际视觉事实，询问情节和目标时长，不虚构分镜。
- 5秒简单反应：可用一个连续镜头，保留主体位置、对象、动作变化，不强塞四镜。
- 30秒连续对话：按真实说话时间与表演切镜，最后精确到30秒；不继承长剧本Skill的27–28秒默认值或延长片段审批。
- 原句跨镜：在首次发声处写【对白】角色：“原文”（声音连续至8秒），后镜只写该角色声音继续；检查发声开始至8秒的可用时间，不重复原句。
- 情节过多或台词超时：指出无法同时满足的条件，询问删减或调时长，不输出表面合规却演不完的脚本。
