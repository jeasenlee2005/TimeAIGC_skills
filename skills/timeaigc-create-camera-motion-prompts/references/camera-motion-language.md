# 可执行的中文运镜语言

## 1. 先判断变化来源

把画面变化拆为四类，避免仅凭主体变大或位置改变就判断运镜：

1. **主体运动**：主体靠近、远离、横穿、转身或改变姿态，摄影机可能不动。
2. **机位原地转动**：摄影机位置不变，只改变朝向。
3. **摄影机空间位移**：摄影机靠近、远离、横移、升降、跟随或围绕主体。
4. **光学与焦点变化**：改变焦距或焦点平面，不等于摄影机位移。

比较首尾帧时优先观察：

- 主体与背景是否产生视差；
- 前景遮挡关系是否变化；
- 背景覆盖范围和透视是否变化；
- 主体自身姿态、朝向与位置是否变化；
- 清晰区域是否从一个对象转到另一个对象。

只有主体比例变大而缺少视差证据时，至少存在三种可能：主体靠近、推镜头、变焦镜头。根据用户意图选择时必须标明假设。

## 2. 受控术语

| 类别 | 受控术语 | 可执行含义 | 使用要点 |
|---|---|---|---|
| 基础形态 | 固定镜头 | 摄影机位置与朝向不变 | 必须写在提示词开头；让表演、画内运动、变焦或移焦承担变化 |
| 原地转动 | 摇镜头 | 机位不变，水平方向转动 | 写明向左或向右、跟随对象和停止构图 |
| 原地转动 | 俯仰镜头 | 机位不变，垂直方向转动 | 写明上摇或下摇、揭示对象和停止高度 |
| 空间位移 | 推镜头 | 摄影机向主体或目标靠近 | 用于收紧注意、逼近或揭示细节；背景视差应合理 |
| 空间位移 | 拉镜头 | 摄影机远离主体或目标 | 用于揭示环境、关系、后果或孤立感 |
| 空间位移 | 跟镜头 | 摄影机随移动主体保持相对关系 | 写明跟随方位、距离与主体路径 |
| 空间位移 | 环绕镜头 | 摄影机围绕主体改变观察角度 | 写明方向、弧度或停止方位；确认空间无遮挡且不穿模 |
| 空间位移 | 横移镜头 | 摄影机沿画面左右或主体侧向移动 | 适合平行跟随、遮挡揭示或空间关系变化 |
| 空间位移 | 升降镜头 | 摄影机改变垂直高度 | 写明上升或下降、起止高度感与揭示内容 |
| 光学变化 | 变焦镜头 | 改变镜头焦距，机位可以不动 | 写明放大或缩小视野及视觉目的；不要冒充推镜或拉镜 |
| 焦点变化 | 移焦镜头 | 焦点平面在不同对象间转移 | 明确焦点从何处转到何处；画面需要存在可区分的景深层次 |
| 器材或风格 | 手持镜头 | 以可控的不稳定感拍摄 | 写明晃动强度；不要同时要求绝对稳定或严格对称 |
| 器材或路径 | 摇臂镜头 | 借摇臂形成弧线、升降或越障路径 | 写明起点、弧线路径和结束构图 |
| 器材或路径 | 航拍镜头 | 从空中以稳定路径观察或跟随 | 写明高度、方向和地面主体关系；不要默认高速穿缝 |
| 器材或路径 | FPV 镜头 | 以穿越机式第一人称高速连续穿行 | 写明可通行路线、转向节点与避障空间 |
| 器材或路径 | 索道摄影 | 摄影机沿预设空中索道稳定移动 | 适合跨越长距离或复杂地形；写明索道方向和终点 |

“缓慢、快速、平稳、轻微、顺时针、逆时针、向左、向右、上升、下降”等是修饰语，不是新的运镜名称。用受控术语先命名，再补充修饰语和路径。

## 3. 兼容与冲突

可以在时间足够且先后清楚时组合：

- 固定镜头 + 变焦镜头：机位与朝向不变，只改变视野范围；
- 固定镜头 + 移焦镜头：机位不动，焦点在不同景深层间转移；
- 跟镜头 + 手持镜头：前者说明路径，后者说明稳定风格；只选一个作为主要意图；
- 航拍镜头 + 跟镜头：明确航拍视点与跟随关系，不要重复堆词；
- 摇臂镜头 + 升降镜头：摇臂是器材路径，升降是主要高度变化；写清同一连续运动。

不要在同一连续短镜头中同时要求：

- 固定镜头与摇镜头、俯仰镜头、任何空间位移或手持镜头；
- 推镜头与拉镜头无触发点地同时发生；
- 快速手持运动与完全稳定、精确对称的构图；
- FPV 镜头高速穿行与没有可通行路径的狭窄封闭画面；
- 环绕镜头穿过墙体、人物或不可见的障碍物；
- 变焦镜头承担只有机位移动才能产生的明显视差；
- 移焦镜头在所有对象都处于同一焦平面或要求全景深清晰时发生；
- 一两秒内完成多段位移、复杂表演、焦点转移和完整环境揭示。

## 4. 单图设计规则

- 把图片中的构图和造型视为事实，不重写服装、场景、时间或人物身份。
- 为静态人物优先设计呼吸、视线、衣发、光影或环境微动；没有依据时不要让人物突然奔跑、转身或操作新道具。
- 检查图片是否提供摄影机移动空间。紧贴墙面、狭窄室内或强遮挡场景不宜默认大幅环绕。
- 让结束画面仍可识别原主体，不以炫技把主体移出画面或被遮挡。

## 5. 首尾帧设计规则

1. 逐项列出两帧中的主体比例、位置、朝向、姿态、背景、遮挡和焦点差异。
2. 锁定必须保持的共同元素，识别需要连续过渡的变化。
3. 判断主体运动能否解释差异，再判断是否需要机位运动或光学变化。
4. 选择能到达尾帧且路径最简单的主要运镜。
5. 写清何时启动、如何加速或减速、主体如何同步、何时停在尾帧构图。
6. 若两帧在身份、服装、场景结构或光线方向上不连续，先指出资产连续性问题；不要用运镜词掩盖。

## 6. 画面描述顺序

按以下顺序写成一个自然段，不必显示字段名：

1. 起始构图与主体状态；
2. 主要运镜、方向、速度和路径；
3. 与运镜同步的主体动作；
4. 焦点、前景、光影或环境反馈；
5. 停止点与结束构图；
6. 与任务有关的质感或画质要求。

画质描述只作为收束，不替代镜头逻辑。优先写与素材相关的质感，如“低照度下保留暗部层次”“高速运动中主体轮廓保持清楚”，不要默认追加空泛的超高清或电影级标签。
