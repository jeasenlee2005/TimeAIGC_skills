# 项目文件、资产与全局风格工作流

## 目录

1. 建立项目工作目录
2. 保存步骤一确认版
3. 收集与归档资产图
4. 检查资产完整性
5. 保存全局风格提示词
6. 每个片段开始前重新读取
7. 资源变化与失效范围

## 1. 建立项目工作目录

优先使用用户指定的项目或资产目录。用户未指定时：

1. 查找当前项目中是否已有本任务的 Seedance 工作目录；有则复用。
2. 没有时，在当前项目根目录创建专用工作目录，并遵守该项目 `AGENTS.md` 的命名规则；逻辑名称使用 `seedance25-work`。
3. 不要把用户项目资产放进 Skill 自身的 `assets/`。

在工作目录内使用：

```text
<work-dir>/
├── assets/
│   ├── characters/
│   └── scenes/
└── state/
    ├── step1-plan-current.md
    ├── step1-plan-vNN.md
    ├── asset-manifest.md
    └── global-style-prompt.md
```

在状态块中记录 `<work-dir>` 和资产目录的绝对路径，后续始终复用。

## 2. 保存步骤一确认版

用户明确确认步骤一后：

- 将完整方案原文保存为 `state/step1-plan-vNN.md`；包含所有片段、出场角色、场景、角色状态、剧情和对白，不得只存摘要。
- 同步更新 `state/step1-plan-current.md`，使其始终等于最新确认版。
- 返回步骤一修改并再次确认时，新建下一版本文件并更新 `step1-plan-current.md`；保留旧版本用于追踪。
- 后续对话发生上下文压缩时，以 `step1-plan-current.md` 为唯一有效基线，先完整读取再继续，不凭记忆重建。

步骤一尚未确认时可以保留对话草稿，但不要覆盖 `step1-plan-current.md`。

## 3. 收集与归档资产图

根据确认版步骤一汇总全部出场角色和场景，向用户一次性索取对应资产。接受两种方式：

### 用户提供文件夹

- 记录用户给出的绝对路径。
- 递归列出支持的图片文件，按角色和场景建立映射。
- 文件名或目录归属不明确时，列出图片并请用户确认对应对象。
- 不移动或改名用户原目录中的文件。

### 用户直接提供图片

- 将附件复制到 `<work-dir>/assets/characters/` 或 `<work-dir>/assets/scenes/`，保留原文件。
- 使用稳定、无冲突的文件名，例如 `character-角色名-01.png`、`scene-场景名-01.jpg`。
- 无法判断人物、场景或版本时先询问映射，不能凭猜测命名。

在 `state/asset-manifest.md` 中记录：

```markdown
# 资产清单

- 资产模式：有资产图 / 用户明确声明无资产图
- 资产根目录：绝对路径

## 人物
- 角色甲：绝对路径 1；绝对路径 2

## 场景
- 旧车站候车厅：绝对路径 1
```

## 4. 检查资产完整性

逐项对照 `step1-plan-current.md`：

- 每个出场角色是否有资产图，或用户是否明确说明该角色无图；
- 每个场景是否有资产图，或用户是否明确说明该场景无图；
- 所有清单路径是否存在、可读取且确实为图片；
- 多套服装、年龄、伤势状态或场景时段能否映射到正确片段。

只说“暂时没有发图”不等于声明无资产图。只有用户明确表达“没有资产图”“本项目不用资产图”等含义，才能记录无资产模式。存在任何未解决缺口时停止，不进入步骤二。

## 5. 保存全局风格提示词

要求用户提供并确认：

- 影片整体风格的简短定义；
- 一份会在所有片段中复用的完整全局风格提示词。

将用户确认的提示词原文保存为 `state/global-style-prompt.md`。不要擅自补写、润色或把它复制进步骤二代码块。步骤二只需读取并贯彻其色彩、材质、时代、媒介、镜头质感和人物表现规则。

## 6. 每个片段开始前重新读取

每次执行步骤二，即使上一片段刚完成，也依次：

1. 完整读取 `state/step1-plan-current.md` 中目标片段及必要的前后连续性。
2. 完整读取 `state/global-style-prompt.md`。
3. 读取 `state/asset-manifest.md`，找出目标片段涉及的全部人物与场景资产。
4. 用可用的图片查看工具逐张打开这些资产图；多角度、多服装和场景细节图都要查看。
5. 记录本次实际读取的文件路径，再开始设计镜头。

路径失效、图片打不开或资产与片段版本不匹配时停止并请求修复。不得以“此前已经看过”或对话记忆代替重新读取。

## 7. 资源变化与失效范围

- 替换人物或场景资产：依赖该资产的已完成分镜过期。
- 修改全局风格提示词：所有已完成分镜过期。
- 新增补充角度但不改变造型：既有分镜可保留；后续分镜读取新资产。
- 步骤一新增角色或场景：返回资源准备阶段，补齐或明确声明无图后才能继续。
