## 1. 选择顺序

先确定镜头要让观众知道或感受什么，再按以下顺序选择：

1. 叙事对象：环境、人物关系、动作还是细节；
2. 景别与机位：决定信息范围和权力关系；
3. 构图与焦点：只在需要时强化观看顺序；
4. 运镜：表达揭示、追随、逼近、疏离或冲击；
5. 焦段、景深和遮挡：只用于加强已确定的意图。

## 2. 景别与叙事功能

| 景别 | 主要用途 | 常见风险 |
|---|---|---|
| 极特写 ECU | 眼睛、手指、机关等关键细节 | 缺少空间依据 |
| 特写 CU | 强调表情、反应和说话状态 | 连续使用会失去节奏 |
| 中近景 MCU | 同时看清表情和上肢动作 | 不适合展示全身发力 |
| 中景 MS | 对话、手部动作、人物关系 | 背景信息可能不足 |
| 全景 WS | 完整动作、人物与空间位置 | 微表情不可见 |
| 远景/建立镜头 | 交代地点、规模、方向和气氛 | 时长太短时信息读不完 |

景别变化应服务信息递进。不要为了“电影感”机械按远景→特写排列。

## 3. 机位与构图

每个镜头都要判断主体位置、视线空间、运动空间和前中后景，但构图术语不是每镜必填项。普通功能镜头优先保持主体明确、空间简单和透视自然；只有构图能表达关系、威胁、秩序或揭示时才写出专门术语。角色近景、中近景和特写避免连续机械居中，优先根据情绪使用三分、非对称、留白、前景遮挡、门窗框或阴影切割；中心构图必须有明确的叙事理由。

- 平视：中性、贴近人物经验。
- 低机位仰拍：强化力量、压迫或尺度；不要默认等同英雄感。
- 高机位俯拍：展示位置关系、脆弱或控制。
- 鸟瞰：说明路线、群体调度或图案关系。
- 主观视角：让观众共享角色看到的信息，必须与前后视线匹配。
- 过肩镜头：明确谁的肩背位于左侧或右侧前景、焦点人物位于哪个区域，并保持对话轴线；不必强行规定精确遮挡比例。
- 三分构图：明确主体落在哪条三分线或交点，另一侧为视线空间、运动空间还是环境信息。
- 对称构图：明确左右对称或上下对称、实体中轴及两侧内容。例如以门框为竖直中轴，角色甲在左侧门扇前、角色乙在右侧等距位置。
- 三角构图：指出三个视觉支点的位置与层次。例如前景左下的道具、中景右侧的人物和背景中央的出口构成斜向三角。
- 留白构图：明确主体位置、空区位置和承载留白的环境内容。例如人物压在右下三分区，左上大面积暗墙与薄雾形成威胁性负空间；不要把留白写成纯白。
- 荷兰角：表达失衡；有剧情依据时使用，不作为通用悬疑修饰。

使用特殊构图术语后，只补充实现它所必需的画面几何关系、主体位置或前中后景。只写术语视为未完成，但也不要为完整描述而叠加无关人物、道具、精确比例和多条运动路径。

## 4. 运镜

| 运镜 | 可执行含义 | 合适场景 |
|---|---|---|
| 固定机位 | 机位不动，让表演或画内运动主导 | 对峙、等待、反应 |
| 推镜 | 摄影机接近主体 | 注意力收紧、揭示情绪 |
| 拉镜 | 摄影机远离主体 | 揭示环境、孤立或结果 |
| 横移/轨道移 | 与主体平行移动或横向揭示 | 行走、空间关系、遮挡揭示 |
| 跟拍 | 保持与移动主体的关系 | 奔跑、追踪、连续动作 |
| 摇镜 | 机位固定、镜头旋转 | 跟随视线或重新构图 |
| 升降 | 改变高度并揭示尺度 | 建立空间或情绪转折 |
| 环绕 | 围绕主体改变背景关系 | 对峙、眩晕、关系变化 |
| 手持 | 可控的不稳定运动 | 紧迫、主观混乱 |
| 快速摇镜 | 快速转向并产生运动模糊 | 冲击转场或突发反应 |
| 希区柯克变焦 | 机位移动与反向变焦同步 | 空间压缩、认知冲击 |
| FPV 穿梭 | 高速连续穿越空间 | 路径清楚的运动段落 |

一个 1–3 秒镜头通常只保留一个主要运镜。若组合运镜，说明先后关系和触发点。

## 5. 焦点、焦段与前景

- 先说明焦点落在哪个主体，再决定浅景深或深景深。
- 广角强化空间和近大远小；长焦压缩空间并隔离主体。焦段应与机位距离和叙事目的相符。
- 拉焦用于同一镜头内转移叙事重点，明确从谁/什么拉到谁/什么。
- 虚焦前景用于增加层次、偷窥感、遮蔽或转场。确保不会遮掉关键动作和口型。
- 光圈数值不是质量词。只有需要稳定景深意图时才写具体值。

## 6. 对话覆盖

- 单人短句：中近景或特写承载表情与口型。
- 双人对话：先用双人镜头建立轴线，再用过肩正反打；不要无故跨轴。
- 长句：可以保持台词连续，同时切到听者反应、手部细节或环境威胁。
- OS/旁白：不要求说话人口型；画面应补充或反衬内容，不要逐字图解。
- 台词跨镜时标明声音连续，避免同一句在多个镜头重复。
- 不把对白和旁白固定放在镜头描述末尾。按照镜头内的时间顺序，在动作触发点插入语言，再继续描述同步动作或画面反馈。
- 优先使用“一边动作一边说”“动作进行时开口”“话音未落，环境随即变化”等同步关系；只有剧情明确要求时才写成动作完成后再说。

## 7. 多人空间与背景角色

拆镜前先建立片段空间图，标记每个出场角色相对摄影机、主体、门窗、桌椅和主要光源的位置。逐镜根据景别、机位、焦段、遮挡和镜头朝向判断谁会入画：

- 镜头主体：完整描述造型、动作、表情、视线和受力。
- 背景入画角色：即使没有台词或剧情动作，也简洁写明姓名/身份、后景层级、相对大小和简单状态。距离很远时可写“角色乙在后景远处，画面中很小”，不要添加清晰五官、服装纹理或复杂动作。
- 前景遮挡角色：写明其肩背、侧脸或肢体位于哪侧和基本焦点关系，无需精确遮挡百分比。
- 画外角色：确认取景范围确实不包含该角色后可以不写；不能仅因其“没有戏份”就默认消失。
- 运镜途中入画：说明角色在何时从画外进入哪一层空间，或被前景遮挡后何时显露。

空间无法从剧本确定时，先做不改变剧情的保守调度，并在片段内保持；若选择会改变人物关系或行动逻辑，向用户确认。

优先用自然的前大后小、遮挡、虚实和层级变化表达空间。不要让前景、中景、后景人物同时拥有相同尺寸和细节强度，也不要为了交代所有角色把他们强行塞进同一取景范围。

## 8. 避免冲突

不要在同一短镜头中同时要求：

- 固定机位与跟随主体移动；
- 极浅景深下前后景同时锐利；
- 长焦空间压缩与夸张的广角透视；
- 快速手持追拍与完全稳定、精确对称构图；
- 主体背对镜头却要求清晰口型和完整面部微表情；
- 远景中看清瞳孔、睫毛或嘴角极细微变化；
- 后景远处小人物同时呈现清晰五官、服装纹理、复杂手势和准确口型；
- 为满足构图说明而让多个不同距离的角色保持相同画面比例；
- 1 秒内完成复杂走位、完整长句、拉焦、环绕和爆炸反馈。

冲突时优先保留剧情信息和表演，再简化摄影装饰。
