# 两阶段图像提示词优化

把复杂场景改写为“先建立完整空间，再进行受控细化”的两阶段提示词。默认沿用用户语言、题材和审美，不擅自改变叙事内容。

## 工作流

1. 提取用户真正想保留的内容：场景、主体、镜头、空间结构、视觉中心、光线、色调、关键道具、氛围和限制。
2. 执行过载与冲突检查。
3. 将内容划分为结构锚点、叙事道具和材质点缀。
4. 编写第一阶段基础图提示词，优先保证几何、透视、比例和光线统一。
5. 编写第二阶段图像编辑提示词，锁定第一阶段构图，只增强允许变化的内容。
6. 简要说明关键修改；只有用户指定模型、接口或尺寸时才给参数建议，不猜测未确认的参数。

编写两阶段提示词前，读取 [references/prompt-templates.md](references/prompt-templates.md)。

第一阶段使用 GPT Image 2、用户询问 GPT Image 2 参数，或需要解释本工作流依据时，同时读取 [references/openai-gpt-image-2-guide.md](references/openai-gpt-image-2-guide.md)。其中的产品参数是带日期的官方文档摘要；若用户要求“最新/当前”信息、API 参数会影响执行，或本地摘要与实际接口不一致，重新查阅官方 OpenAI documentation，不把本地快照当成实时规范。

## 过载与冲突检查

重点检查并修复：

- 同时要求可见标语或编号，又要求无文字。
- 同时指定多个互不兼容的镜头、媒介、时间或主光源。
- 把碎石、裂缝、烟尘、粒子、余烬、破损设备等破坏性元素扩散到全画面。
- 每个区域列出大量同等级小物件，导致没有视觉中心。
- 使用“8K、HDR、超高细节、极致材质”等质量词堆叠代替空间描述。
- 既要求深景深，又要求大片前后景虚化；既要求自然纪实，又要求夸张棚拍或游戏渲染。
- 使用“若干、几把、大量、推断”等模糊数量，使模型自由复制物件。
- 负面限制与正面内容互相抵消。

不要只删除冲突；把用户意图改写成可执行约束。例如将“墙上有安全标语，但无文字”改成“保留褪色油漆块和抽象警告图形，没有可辨认文字”。

## 内容分级

使用三级层级，数量按场景复杂度调整，不机械凑数：

- **结构锚点**：决定画面是否成立的建筑、主体、通道、地平线或大型设备。通常保留 3–5 个，必须明确位置与关系。
- **叙事道具**：帮助讲故事的中型物件。按区域少量分布，明确数量、位置、尺度和是否遮挡视觉中心。
- **材质点缀**：锈迹、灰尘、苔藓、油污、颗粒、余烬等。限制范围、密度和亮度，不让其变成新的主体。

将破坏描述局部化：指定一处主裂缝、一个下沉角、两三处屋顶孔洞，而不是让所有表面同时破裂。将重复风险高的物件改成确定数量，并说明彼此不同。

## 第一阶段：结构稳定基础图

按以下顺序编写，使用短标题和自然语言，不堆砌标签：

1. 单幅连续场景与叙事时刻。
2. 画幅、机位、镜头、视角和透视。
3. 前景、中景、背景或左、中、右的空间布局。
4. 结构锚点及其相互关系。
5. 克制的叙事道具。
6. 唯一主光源、辅光和色彩结构。
7. 摄影或绘画媒介、真实材质和质量目标。
8. 视觉优先级与严格限制。

明确写出“单幅、连续、统一透视、统一比例、统一光源”。广角场景要指定消失点、相机高度，并排除鱼眼畸变。真实电影感应使用可观察的摄影特征，例如自然曝光、柔和高光过渡、胶片颗粒和真实材质，不依靠质量热词。

第一阶段不要承载所有微小道具。若用户坚持全部保留，把次要物件写成区域性组群并声明它们不抢夺视觉中心。

## 第二阶段：保构图细化

第二阶段必须假设第一阶段图像作为输入。提示词首先列出必须保持不变的项目：

- 摄影机位置、镜头角度、画幅和透视。
- 建筑结构、主体几何、空间比例和地平线。
- 关键物件的数量、位置、朝向和轮廓。
- 主光方向、阴影方向、色调和视觉中心。

随后只列允许增强的内容，例如材质差异、局部磨损、空气颗粒、接触阴影、倒影、胶片质感或少量次要道具。每个新增物件必须说明位置、依附表面、尺度和数量。

使用“只增强/只修改 X，保持其他内容不变”的编辑语言。结尾禁止新增大型物体、复制物件、扩大破坏范围、改变构图、改变光源或生成可辨认的随机文字。

若第一阶段结构本身错误，不要用第二阶段掩盖；先生成一条单项结构修复提示词，再进行材质增强。

## 输出格式

默认输出：

1. **诊断**：用 3–6 条指出主要冲突、过载点和降级策略。
2. **第一阶段提示词**：可直接交给 GPT Image 2 或基础文生图模型。
3. **第二阶段提示词**：可与第一阶段图片一起交给 Nano Banana Pro 或图像编辑模型。
4. **使用建议**：简述选图标准和下一轮单项修改方法。

把两段提示词作为完整可复制的成品，不在提示词内部加入解释、免责声明或模型教学。

## 质量标准

交付前确认：

- 画面只有一个主要空间和清晰视觉中心。
- 结构锚点的位置、数量和关系可被直接画出。
- 破坏、烟尘、粒子和纹理均有范围限制。
- 正面描述与负面限制不冲突。
- 第二阶段清楚区分保持项、修改项和禁止项。
- 用户的题材、故事信息与核心审美没有被优化掉。
