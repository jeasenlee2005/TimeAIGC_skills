# 两阶段提示词模板

仅把模板中与任务相关的段落填入最终提示词。不要机械保留空字段。

## 第一阶段：基础图

```text
生成一张单幅、连续、完整的[摄影/插画/电影场景]：[一句话场景与叙事时刻]。[人物或动物限制]。

【镜头与构图】
[画幅]，[镜头焦段或景别]，摄影机位于[位置与高度]，[视角]。采用[一点/两点/自然]透视，视觉中心是[主体]，消失点位于[位置]。这是一个真实连续空间，不是拼贴或多个场景的组合。

视觉优先级：
1. [第一视觉中心]
2. [第二视觉中心]
3. [第三视觉中心]

【空间结构】
前景：[连续地面/引导线/少量道具]
中景：[主要主体、建筑或大型设备]
背景：[纵深终点、环境轮廓]

所有结构遵循统一透视、比例、地平线和重力。结构损坏仅发生在[明确局部]，其余主体保持完整可辨。

【叙事道具】
[区域]放置[确定数量与类型]，自然错落、彼此不同、保持间距，不遮挡[视觉中心]。其余微小物件只作为低对比背景信息。

【光线与色彩】
唯一主光源来自[方向与来源]；[可选辅光]只影响[局部范围]。所有投影、反射与体积光方向一致。主色为[色彩]，[点缀色]仅用于[局部]。

【媒介与材质】
Photorealistic / [目标媒介]。[自然曝光、胶片颗粒、高光过渡、阴影层次]。[关键材质]具有真实重量、磨损与尺度差异。远处细节自然递减，不平均锐化。

【严格限制】
优先保证[结构列表]完整连贯，其次表现[主要道具]，最后表现材质点缀。
不要[拼贴、重复、畸变、全局破坏、过量粒子、随机文字、质量风格问题]。
```

## 第二阶段：输入图细化

```text
使用输入图作为唯一构图基准。

【必须保持不变】
保持摄影机位置、镜头角度、画幅、透视、地平线、[建筑/主体]结构、[关键物件]数量与位置、主光方向、阴影方向、色调和视觉中心完全不变。

【只允许增强】
只增强[材质、磨损、接触阴影、倒影、空气、胶片质感]。增强必须依附现有表面并符合原图的比例、重力、透视和光照。

[如需新增：只在具体位置增加确定数量的次要物件，并说明大小、朝向和依附关系。]

【禁止】
不要改变建筑结构、主体轮廓、构图或光源；不要新增大型物体、复制物件、扩大裂缝或坍塌、增加杂乱程度、生成可辨认随机文字、改变风格或过度锐化。
```

## 单项修复

当基础图只有一个问题时，先使用：

```text
保持原图其他内容完全不变。只修复[一个具体问题]：[期望结果]。保持摄影机、构图、主体位置、光线、色彩和其余物件不变。不要新增或删除其他元素。
```

## 选图标准

第一阶段从结构而不是纹理判断：

1. 透视和地平线是否稳定。
2. 主体轮廓和空间连接是否完整。
3. 光源与阴影是否统一。
4. 关键物件是否数量正确、位置合理。
5. 只有上述条件相近时，才比较材质与氛围。
